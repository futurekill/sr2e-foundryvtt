## Hidden reads the context must carry
- **Settings**: `autoEssence`, `moreMetahumans`, `cybermancy` (in `prepareDerivedData` / `_applyCybermancy`), plus the
  rulesets read through helpers: `isVR2()` (`matrixRuleset`), `isRigger2()` (`vehicleRuleset`), `r2Option(...)`,
  `variableLTGOn()` → `ctx.settings`. Also `utilityOptionsOn()` (`vr2UtilityOptions`; ProgramData, item-data.mjs
  ~1142/1171), which swallows a missing `game` and returns false — a silent wrong answer in Node (PLAN-derive round 5 #1).
- **Registries**: `CONFIG.SR2E.languageFamilies` (the synthetic LinguaSoft skill, actor-data.mjs ~927) →
  `ctx.registries.languageFamilies`.
- **Localization**: `_collectItemModifiers`, `_applyLimbAverages`, `_calculateAttributeValues` call `game.i18n` to
  label attribute sources. The pure layer returns label KEYS (+ params); the Foundry adapter and the creator localize.
- **Active Effects**: `_applyCybermancy` and `_attributeEffectSources` read `parent.appliedEffects` → `ctx.effects`.
- **Other documents**: `_applyCybermancy` uses `fromUuidSync`; `sustainPenalty` → `elementalHolderOf` scans
  `game.actors` for bound elementals → `ctx.lookup` (absent / unavailable, D9).
- **The parent's source**: `matrixMode`, the VCR fallback, `_snapshotActiveDeck`, `_derivePersona` read
  `parent._source` → `ctx.source`.
- **Event logs and folds**: `eventsOf` (VR2 connection, deck), `substancesOf` (Essence loss, substance clock in flags),
  `foldMbw` / `foldCym` (`_wareCyberInteractions`) → `ctx.events` / `ctx.flags`.

## Helpers to split into pure files before they can move
They read only flags/sources, but live in gameplay modules that import Foundry-coupled code, so `module/derive/`
can't import them in Node: `drugs.mjs` `substancesOf`, `workingImplant`, `drugsInForce` (and `ledgerOf`,
`substanceNow`); `elementals.mjs` `elementalHolderOf` (its `game.actors` scan becomes a `lookup`); `claims.mjs`
`eventsOf` / `markersOf`; `programming.mjs` `programmingState`; `effects-compat.mjs` `effectChanges` / `changeIsAdd`
(read `game.release` only for the v13/v14 shape — take the shape from the context); `vr2-mode.mjs` `variableLTGOn`.
Each moves to `module/rules/` (or a new `module/derive/` helper) with its module re-exporting it, so callers don't
change.
